# OIBSIP_DataAnalytics_04
# Data Cleaning and Preprocessing

## Project Overview

This project demonstrates the process of cleaning and preprocessing a dataset containing missing values and inconsistent records. Data cleaning is an essential step in data analysis as it improves data quality and ensures accurate insights and decision-making.

The project focuses on identifying missing values, handling incomplete records, and preparing the dataset for further analysis using Python and Pandas.

---

## Key Objectives

1. Detect missing values in the dataset.
2. Handle null values using appropriate techniques.
3. Replace missing numerical values with statistical measures.
4. Fill missing categorical values with meaningful labels.
5. Create a clean and consistent dataset.
6. Prepare the dataset for future data analysis and machine learning tasks.

---

## Technologies Used

- Python
- Pandas
- NumPy
- Google Colab

---

## Dataset Description

The sample dataset contains employee information including:

- Name
- Age
- Salary
- Department

The dataset intentionally includes missing values to demonstrate various data cleaning techniques.

---

## Data Cleaning Steps

### 1. Missing Value Detection
- Identified null values using Pandas functions.

### 2. Numerical Data Handling
- Missing Age values replaced with the mean age.
- Missing Salary values replaced with the mean salary.

### 3. Categorical Data Handling
- Missing Department values replaced with the most frequent category.
- Missing Name values replaced with "Unknown".

### 4. Dataset Validation
- Verified that all missing values were successfully handled.

---

## Results

After preprocessing:

- Missing values were removed.
- Dataset consistency was improved.
- Data became ready for analysis and machine learning applications.

---

## Conclusion

Data cleaning is a critical step in every data analytics workflow. This project demonstrates how missing values can be identified and handled effectively using Python, ensuring higher data quality and more reliable analytical outcomes.
